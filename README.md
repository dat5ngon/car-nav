# Car Nav

Lightweight car navigation using OpenStreetMap. Zero tracking, no API key, no build tools, runs entirely in the browser.

## Features

- **Search destinations** via Nominatim (OpenStreetMap)
- **Turn-by-turn navigation** with real-time GPS tracking
- **Route options** -- avoid tolls, highways, ferries (with custom OSRM)
- **Satellite view** toggle (Esri World Imagery)
- **Recent destinations** history
- **Dark theme** optimized for driving
- **Completely free** -- no API key, no billing, no Google dependency

## How It Works

1. Open the app -- map loads immediately
2. Search for a destination
3. View the route with duration and distance
4. Tap "Start" for turn-by-turn navigation
5. GPS tracks your position and advances instructions automatically

## Privacy

- No analytics, no tracking
- All data stored in browser localStorage only
- Uses public OpenStreetMap services
